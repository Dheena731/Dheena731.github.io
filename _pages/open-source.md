I build practical Python tools for LLM development, machine-learning environments, and backend engineering.

## [toolproxy](https://github.com/Dheena731/toolproxy)

A provider-agnostic wrapper that adds function/tool calling to LLMs, including models without native tool support. Supports native and emulated tool-call paths, synchronous and asynchronous execution, retries, repair, caching, loop detection, and usage budgets.

[GitHub](https://github.com/Dheena731/toolproxy) · [PyPI](https://pypi.org/project/toolproxy/) · `pip install toolproxy`

## [mlenvdoctor](https://github.com/Dheena731/Ml-env-doctor)

A diagnostic CLI for PyTorch, TensorFlow, and JAX environments. Checks CUDA and driver visibility, dependency mismatches, and generates reports and proposed fixes through a plan–dry run–apply–verify workflow.

[GitHub](https://github.com/Dheena731/Ml-env-doctor) · [PyPI](https://pypi.org/project/mlenvdoctor/) · `pip install mlenvdoctor`

## [boostapi](https://github.com/Dheena731/boostapi)

A FastAPI scaffolding toolkit with asynchronous SQLAlchemy, Alembic migrations, Redis caching, JWT authentication, rate limiting, and OpenAPI support.

[GitHub](https://github.com/Dheena731/boostapi) · [PyPI](https://pypi.org/project/boostapi/) · `pip install boostapi`
